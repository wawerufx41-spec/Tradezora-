Sandbox trade outcome controls

Set six contract win rates for all users. These rates apply to internal sandbox trades funded by either test funds or the sandbox real-balance ledger. Saving overwrites per-user rates for existing non-admin users; new users inherit platform defaults. This does not affect broker-connected production execution.

Real Test Mode — sandbox only

Separate persistent settings for simulated testing only. This panel does not enable broker execution and cannot change real-money trades, balances, payouts or the ledger.

Company-Funded Real Account Credits

Grants update the same real-account balance used by internal-engine trades, deposits, and withdrawal requests. Only the unspent company-credit portion can be reversed; genuine deposits and other funds are protected. Grant only company liquidity that TradeZora is prepared to back. Amounts are limited to $10–$1,000 per action.
